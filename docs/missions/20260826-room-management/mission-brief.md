# Mission Brief: 進捗部屋管理画面を実装する

## Intent

- **動機**: 進捗部屋のCSV一括登録と削除が管理画面にまとまっておらず，管理者が予約済みの部屋を確認して整理できないため．
- **目的**: 特権ユーザーが`/rooms/manage`でCSV一括登録と，現在以降に予約されている確認済み進捗部屋の選択削除を完結できるようにする．
- **スコープ内**: `/rooms/manage`の追加，CSV登録UIの統合，将来・進行中かつ確認済みの進捗部屋の日時順表示，複数選択，削除確認，選択した部屋の直列削除，部分失敗の表示，既存`/rooms/new`からの互換導線，管理画面へのヘッダー導線．
- **非目標**: 進捗部屋の編集，通常フォームによる1件登録，OpenAPI生成型の手編集，バックエンドへの一括削除API追加，進捗部屋カレンダーの表示変更．
- **制約**:
  - must: 既存の`POST /rooms/all`と`DELETE /rooms/{roomID}`を使用し，`src/lib/api/schema.d.ts`を手編集しない．
  - must: 削除は確認操作を経て，特権ユーザーだけが開始できるUIにする．
  - must: ID単位のDELETEは同時実行せず，1件の応答後に次の1件を送る．
  - must: 削除が一部失敗した場合も残りの削除を続け，成功分と失敗分を区別し，失敗した部屋を再選択できる状態に保つ．
  - should: 管理画面の情報密度を優先し，既存のUnoCSS tokenとUI部品を再利用する．

## Conceptual Plan

- **候補と比較**: A案は`GET /rooms`の結果を画面側で`verified`により絞り，選択したIDごとに既存DELETEを直列実行する．現行APIだけで完結する一方，削除件数に比例して完了までの時間が延びる．B案はバックエンドへ確認済み絞り込みと一括削除APIが追加されるまで待つ．通信回数は減らせるが，Issue #211を現行APIだけで完結できない．
- **合意するアプローチ**: A案で，特権ユーザー向け`/rooms/manage`へCSV登録と削除一覧を統合する．現在進行中または将来であり，かつ`verified === true`の部屋だけを開始時刻順に表示する．確認ダイアログ後は，選択したIDごとにDELETEを1件ずつ送り，応答後に次の削除へ進む．`/rooms/new`は管理画面へredirectし，既存リンクを壊さない．
- **チェックポイント**: 管理画面の空・読込・取得失敗状態，選択と確認ダイアログ，削除の全成功・部分失敗，CSV登録の成功・失敗，旧URLからの遷移を確認する．
- **スローモート・トリガー**: 現行APIで進行中・将来の部屋を取得できない，DELETEの権限仕様が`privileged`と矛盾する，ID単位DELETEでは許容できない原子性が必要と判明した場合は実装を止めて相談する．
- **承認**: approved
- **承認者 / 日時 / 根拠**: user / 2026-09-02T12:47:13Z / 「verifiedだけ取得するようにしてください」「削除も直列に送るならそれでよい」という指示により，確認済みroomへの限定とID単位DELETEの直列化を承認．
- **追加判断**: 確認済みroomのうち，現在ユーザーの`userId`がroomの`admins`に含まれる場合だけチェックボックスを有効にする．削除権限のない行には理由を表示する．`dateBegin`は当日0時とし，終了済みroomをクライアントで除外する．

## Autonomy Envelope

### may_decide

- 承認済みプロパティを変えない範囲でのコンポーネント分割，命名，UnoCSS class，表示文言．

- Conceptual Plan または受け入れプロパティを確定，変更するとき

- OpenAPI契約やバックエンド実装の変更が必要になったとき．
- 特権ユーザー以外にもCSV登録または削除を許可する要件へ変更するとき．
- 削除対象の期間または部分失敗時の挙動を変更するとき．

### prohibited

- `src/lib/api/schema.d.ts`の手編集．

- **調査結果**: バックエンドの`dateBegin`は`time_start >= dateBegin`として処理されるため，進行中の部屋を含めるには当日開始時刻から取得し，終了済みをクライアントで除く必要がある．削除権限は`privileged`ではなく，対象roomの`admins`にリクエストユーザーが含まれるかで判定される．CSV登録では登録者だけが`admins`へ設定される．
