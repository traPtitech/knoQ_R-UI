# イベント検索ページ

## 目的と範囲

/eventsと/searchから既存APIでイベントを検索できるようにする．検索条件，取得状態，結果カードが対象．バックエンド，APIスキーマの変更は含めない．

## 合意した仕様

- キーワードの下に，既存SelectMenuによるタグ・ユーザー・グループの複数選択を置く．選択済み条件は入力枠内の下段にチップ表示する．同種条件はOR，異種条件はAND．キーワードは取得結果の名前と説明へ適用する．
- 開始日・終了日のみアコーディオンに置く．日付はローカル日付で，終了日全体を含む．過去イベントは初期OFFで，開催中を含む．
- 候補取得はuseApiFetchのキャッシュを使用し，ユーザー一覧は参加者表示と同じキーを使う．候補の専用待機表示や操作制限は設けず，失敗時の再試行のみ残す．
- 初回取得は「検索中…」だけを表示する．以降の検索中は表示中の結果を維持し，失敗時には消す．HTTP 401も通常の取得失敗表示に統一する．
- 開始日が同じ結果は日付見出しをまとめる．カードの開始・終了時刻に日付を付け，参加者アイコンは右下に最大8人と残り人数を表示する．アイコンのホバーアニメーションは付けない．共通カードなので他の一覧にも反映される．
- sandboxは提出対象外とし，ページ・ルート・本体の差し替え用実装を削除する．検討時の内容はバックアップブランチに保全する．

## 受け入れ条件と検証方針

- 両検索ルートで共通UIを使い，条件と結果が一致する．
- 日付境界，複合条件，0件，失敗と再試行，古い応答の無視を単体テストで確認する．
- ビルド・型検査・変更ファイルのLintを確認する．表示の検討は削除前の開発用sandboxで行った．
- 方針・テスト設計は2026-09-09に承認済み．その後のUI変更は本タスク内の指示に基づく．2026-09-16にローカルコミットの再構成を依頼された．
