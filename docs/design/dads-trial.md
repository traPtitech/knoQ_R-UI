# DADSを参考にした試作デザイン

対象は基本コンポーネント，ホーム，イベント作成画面．採用前の試作である．デザインの値は`uno.config.ts`を正本とする．

既存のブランド配色を維持する．主操作は`#0E9888`，リンクは`#009688`とし，背景，本文，罫線，状態色も元の色定義を使う．Noto Sans JPを継続し，本文は16px，見出しは太字にする．4px単位の既存余白を使い，フォームのまとまりは罫線と見出しで区切る．ボタンと入力欄は48px以上を基本とし，キーボードフォーカスは既存のアクセント色と白の二重線で示す．動きは操作の補助に限り，reduced-motionへ対応する．

ホームは今日の部屋とイベントを主領域に，今後の自分のイベントを補助領域に配置する．モバイルでは縦に積む．作成画面は基本情報，場所と日時，管理者の順序を維持し，必須・任意と入力エラーを項目の近くに置く．ユーザーの指示により，追加したキャッチコピー，見出しの補助文言，フォームの補足説明は削除した．

[DADSの基本デザイン](https://design.digital.go.jp/dads/foundations/)と[ボタン](https://design.digital.go.jp/dads/components/button/)，[入力欄](https://design.digital.go.jp/dads/components/input-text/)を参考にした．DADSの完全準拠やアクセシビリティ認証を示すものではない．既存ロゴ，ルート，API契約は継続する．
